# گزارش تطبیق اپ با قوانین وب‌سایت (Rayan Garden)

اصل: وب‌سایت و بک‌اند مرجع تمام قوانین‌اند؛ اپ هیچ قانون مستقلی تعریف یا اعمال نمی‌کند.
وضعیت‌ها: **API** = مقدار از سرور خوانده می‌شود · **سرور** = اپ چیزی اعمال نمی‌کند و تصمیم با سرور است ·
**آینه UI** = فقط محدودیت پیمایش تقویم · **نیازمند تأیید** = بدون دیدن پاسخ واقعی API قابل اثبات نیست.

## API یا اطلاعات ناموجود (چیزی اختراع نشد)
1. نمونه پاسخ واقعی `availability.php` (ساختار، و اینکه فاصله ۶۰ دقیقه و تداخل را سمت سرور اعمال می‌کند).
2. نام فیلدهای قیمت، بیعانه و فعال/غیرفعال و نام خدمت در `services.php`.
3. API بررسی وضعیت درخواست با کد پیگیری: اپ چیزی ندارد که صدا بزند، پس صفحه «پیگیری» ساخته نشد.
4. مقدار بازه ۱۲۰ روز از API (فعلاً فقط آینه UI).
5. واحد پول (تومان/ریال) برای نمایش قیمت.
